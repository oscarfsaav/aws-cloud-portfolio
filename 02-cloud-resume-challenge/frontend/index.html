Así ha llegado esta página hasta ti

No es una maqueta: esta web es mi Cloud Resume Challenge, desplegado en AWS. Cada vez que alguien la abre ocurren dos recorridos.

Cargar la página

  1. Tu navegadorPide oscarfragueiro.com.
  2. Route 53Traduce el nombre del dominio a la dirección de CloudFront.
  3. CloudFrontCifra la conexión con HTTPS y sirve la copia más cercana a ti.
  4. S3Guarda los archivos de la página. Es privado: solo CloudFront puede leerlo.

Contar la visita

  1. Tu navegadorEjecuta un pequeño script al cargar la página.
  2. API GatewayRecibe la petición. Solo acepta las que vienen de mi dominio.
  3. LambdaUna función en Python que suma una visita.
  4. DynamoDBGuarda el total. visitas hasta ahora, contándote a ti
